# 有序图库 Lightroom Classic 插件

版本：1.1.0（build 1）

## 使用条件

- macOS，已安装 Lightroom Classic（不支持云版 Lightroom 或 Windows）。
- 同一台 Mac 已安装支持 LR 回传的新版有序图库，并打开目标图库。
- 原图已添加到有序图库并完成索引；外接硬盘需保持连接。
- 插件连接本机图库，不会把照片发送到其他人的电脑。

## 安装（推荐）

1. 下载并解压插件 ZIP。
2. 将 `LumaIndex.lrplugin` 放在固定文件夹，安装后不要移动或删除它。
3. 打开 Lightroom Classic，选择“文件 → 增效工具管理器…”。也可点击导出窗口左下角的“增效工具管理器…”。
4. 点击“添加”，选择 `LumaIndex.lrplugin`，确认插件已启用。
5. 打开有序图库并进入目标图库，在 LR 中选择“文件 → 增效工具额外信息 → 有序图库：检查连接”。

无需双击 `.lrplugin` 或运行安装脚本。

## 遇到 Apple 无法验证安装脚本

点击“完成”，然后按上述增效工具管理器方式安装。不需要关闭系统安全设置，也不需要执行终端命令。

包内“安装插件.command”为可选工具，会将插件复制到当前用户的 Lightroom Modules 目录；不影响上述手动安装方式。

## 从图库打开原图修图或返修

1. 在图库摄影工作台勾选图片，选择“Lightroom Classic”；返修时点击“去返修”。
2. 插件按原图路径定位当前 LR 目录中的照片，保留已有调整；当前目录没有的原图才会导入。
3. 本次选中的原图显示在 LR“有序图库”收藏集组下的独立集合中，支持一次选择多张。
4. 修改完成后，按下面步骤导出回传。回传本地后，仍需在图库点击“上传修图”才会更新交付端。

首次升级到 1.1.0 后请重启 LR，让选图链接处理器生效。插件未启用或交接超过十分钟时，请启用插件后在图库重新打开。

## 修图后回传

1. 在 Lightroom Classic 中选中修好的照片，打开“文件 → 导出”。
2. 点击窗口最上方“导出到：硬盘”，切换为“有序图库”。注意不是下方“导出位置”文件夹菜单。
3. 选择 JPEG 或 TIFF，设置画质、尺寸后导出。
4. 图库将成片保存到原图目录下的“修图”文件夹，并关联原图所在集合。缩略图和浏览图稍后生成。

仅在点击导出时回传，调整 LR 参数不会自动同步。

## 失败与重试

保持目标图库打开，选择“文件 → 增效工具额外信息 → 有序图库：重试未完成回传”。已保存的临时成片不需要重新渲染。

- 提示无法连接：打开新版有序图库并进入目标图库，再检查连接。
- 导出到列表没有有序图库：检查插件管理器是否已添加并启用插件，必要时重启 LR。
- 提示原图不可用：确认原图已入库、磁盘在线、文件未移动。
- 已切换图库：返回原目标图库后重试。
- 渲染失败或暂存复制失败：修正 LR 导出或目录权限问题后重新导出。

## 升级

退出 Lightroom Classic，用新版替换固定位置的 `LumaIndex.lrplugin`，再启动 LR。不要删除待回传文件；本机回传清单独立保存，不在插件目录内。
