有序图库隐私政策

更新日期：2026年9月12日

有序图库是一款本地照片管理应用。本政策适用于当前 Mac App Store 版本。

本地数据处理

应用在你授权后读取所选文件夹中的照片、视频和文件信息，用于浏览、索引、搜索和整理。处理的信息可能包括文件名、路径、拍摄时间、相机和镜头信息，以及文件中已有的地理位置等元数据。

图库索引、评分、标签、评论、相册关系、缩略图和浏览图保存在你的设备上。当前版本未接入广告或第三方行为统计服务，也不将这些图库数据自动上传至开发者服务器。

文件访问权限

应用使用 macOS 文件夹授权和安全作用域书签，以便在后续启动时继续访问你选择的来源。你可以在应用内移除来源。文件移动、重命名和移入废纸篓等操作会按你的指令影响对应原文件。

日志与支持

应用可能在设备上保存运行日志，用于排查问题。日志可能包含文件路径和错误信息。如果你主动联系支持或发送日志，我们会收到你提供的内容，并仅将其用于处理你的支持请求。

购买

应用通过 Apple App Store 提供购买和下载。购买过程中由 Apple 处理的账户、付款及相关数据受 Apple 的隐私政策约束；本应用不直接收集银行卡信息。

数据管理

你可以管理或删除本地图库数据。删除图库索引会丢失其中的评分、标签、评论及相册关系，请提前备份。删除图库数据与删除外部原文件是不同操作。

联系方式

如有隐私相关问题，请联系：dteer@qq.com。

本网站

本网站由 GitHub Pages 托管。访问页面时，GitHub 可能处理 IP 地址、设备信息及访问日志，以提供和保护服务；详情请参阅 GitHub 隐私声明。本网站不添加广告、分析脚本或照片上传功能。
