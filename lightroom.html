Lightroom Classic 插件

将修好的照片从 Lightroom Classic 回传到本机有序图库。

下载插件 1.1.1（ZIP） · SHA-256 校验 · 完整使用说明

安装前准备

适用于 macOS 上的 Lightroom Classic，不支持云版 Lightroom 或 Windows。同一台 Mac 需安装新版有序图库，并将原图加入图库完成索引。

安装插件

  1. 下载并解压，将 LumaIndex.lrplugin 放到固定文件夹，之后不要移动。
  2. 打开 Lightroom Classic → 文件 → 增效工具管理器。
  3. 点击“添加”，选择 LumaIndex.lrplugin，确认启用。
  4. 打开有序图库并进入目标图库，在 LR 的“文件 → 增效工具额外信息”中选择“有序图库：检查连接”。

安装脚本被 macOS 拦截怎么办？

点击“完成”，按上面的增效工具管理器方式安装即可。无需运行安装插件.command，无需关闭系统安全设置。

从图库打开原图

在图库勾选图片并选择 Lightroom Classic，插件会定位原图、保留已有调整，并把本次多选加入独立集合。升级后请重启 LR。

修图后回传

  1. 在 LR 中选中修好的照片，打开“文件 → 导出”。
  2. 将窗口最上方“导出到：硬盘”切换为“有序图库”，不是下方的导出文件夹菜单。
  3. 选择 JPEG 或 TIFF，设置画质与尺寸，点击导出。

成片保存到原图目录下的“修图”文件夹，并关联原图所在集合。插件仅手动导出时回传，不会自动同步编辑操作。

失败后继续

保持原目标图库打开，在 LR 中选择“文件 → 增效工具额外信息 → 有序图库：重试未完成回传”。若渲染或暂存失败，则修正问题后重新导出。

升级

退出 LR，用新版替换固定位置的插件文件夹，再启动 LR。不要删除待回传的临时文件。
